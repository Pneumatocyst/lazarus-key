# Portable tools

The v0.4 Portable Tools Manager installs authorized optional utilities into this directory after downloading them from official upstream sources and verifying their pinned SHA-256 hashes.

Third-party binaries are intentionally excluded from the repository and release ZIPs. The catalog records official sources, versions, licenses, hashes, sizes, launcher paths, and publisher-verification requirements. Each installed tool receives a `.lazarus-tool.json` receipt.

Use **Tool Manager** in the Windows launcher, or see `Scripts\Portable-Tools\README.md` for command-line operation.
